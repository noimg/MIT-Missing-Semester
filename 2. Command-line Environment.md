# 2. Command-line Environment

## Arguments and Globs

1. The `--` is useful when a filename starts with a hyphen (`-`), because the command-line program might otherwise interpret the filename as an option or flag.

2. ```bash
	ls -alth
	```

	- `-a`: Include all files, including hidden files (`.`-prefixed names), as well as `.` and `..`.
	- `-l`: Use long listing format, showing permissions, owner, group, size, and modification time.
	- `-h`: Display file sizes in human-readable format (e.g., `1.1M`, `106M`).
	- `-t`: Sort by modification time, newest first.

3. 

	- `printenv` prints the environment variables currently exported to the environment. It displays their names and values.

	- `export` (without arguments) displays shell variables marked for export, typically in the form of shell commands such as `declare -x PATH="..."` in Bash.

## Environment Variables

1. ```bash
	#!/bin/bash
	
	marco() {
	    MARCO_DIR="$(pwd)"
	    echo "Saved directory: $MARCO_DIR"
	}
	
	polo() {
	    if [[ -n "$MARCO_DIR" && -d "$MARCO_DIR" ]]; then
	        cd "$MARCO_DIR" || return
	        echo "Returned to: $(pwd)"
	    else
	        echo "Error: No saved directory. Run marco first."
	        return 1
	    fi
	}
	```

## Return Codes

1. ```bash
	#!/usr/bin/env bash
	
	count=0
	
	while true; do
	    count=$((count + 1))
	
	    if ./script.sh > stdout.txt 2> stderr.txt; then
	        continue
	    else
	        break
	    fi
	done
	
	echo "Failed after $count runs."
	echo "===== Standard Output ====="
	cat stdout.txt
	echo "===== Standard Error ====="
	cat stderr.txt
	```
