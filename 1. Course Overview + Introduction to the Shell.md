2. `-l` flag displays detailed information.

    | Position   | Meaning                  |
    | :--------- | :----------------------- |
    | 1st char   | File type                |
    | chars 2–4  | Owner permissions        |
    | chars 5–7  | Group permissions        |
    | chars 8–10 | Other users’ permissions |

    First character file types:

    | Char | Type              |
    | :--- | :---------------- |
    | `-`  | regular file      |
    | `d`  | directory         |
    | `l`  | symbolic link     |
    | `c`  | character device  |
    | `b`  | block device      |
    | `s`  | socket            |
    | `p`  | named pipe / FIFO |

    Within each 3-character permission group:

    | Char | Meaning                                   |
    | :--- | :---------------------------------------- |
    | `r`  | read                                      |
    | `w`  | write                                     |
    | `x`  | execute; for a directory, traverse/search |
    | `-`  | permission not granted                    |

3. A glob is a wildcard pattern used to match filenames or strings.

4. | Quoting           | What happens inside                                          |
    | :---------------- | :----------------------------------------------------------- |
    | `'single quotes'` | Enclosing characters in single quotes `'` preserves the literal value of each character within the quotes. |
    | `"double quotes"` | Enclosing characters in double quotes `"` preserves the literal value of all characters within the quotes, with the exception of `$`, \`, `\`, and, when history expansion is enabled, ‘!’. |
    | `$'ANSI quotes'`  | Character sequences of the form `$'string'` are treated as a special kind of single quotes. The sequence expands to string, with backslash-escaped characters in string replaced as specified by the ANSI C standard. Backslash escapes are interpreted, e.g. `\n` = newline, `\t` = tab. Variables are not expanded. |

5. To send stdout and stderr to separate files:
  ```bash
  ls /nonexistent /tmp > stdout.txt 2> stderr.txt
  ```

  To send both stdout and stderr to the same file, redirect stdout first, then make stderr point to where stdout is pointing:
  ```bash
  ls /nonexistent /tmp > combined.txt 2>&1
  ```

6. ```bash
  [ -d /tmp/mydir ] || mkdir /tmp/mydir
  ```

  Or equivalently:
  ```bash
  [ ! -d /tmp/mydir ] && mkdir /tmp/mydir
  ```

7. Because a child process cannot change its parent’s working directory.

  When the shell runs an external program, it typically does:

  1. `fork()` — create a child process
  2. in the child, `exec()` — replace it with the external program
  3. parent shell waits for the child to finish
  4. The child exists

  But `chdir()` only changes the working directory of the calling process — in this case, the child. The parent shell is a separate process and is unaffected. So after `/bin/cd /tmp` finishes, the shell would still be in its original directory.

8. ```bash
  #!/bin/bash
  # check_file.sh - Checks whether a file exists and prints an appropriate message
  # Usage: ./check_file.sh <filename>
  
  # Verify that exactly one argument was provided
  if [ $# -ne 1 ]; then
      echo "Usage: $0 <filename>"
      exit 1
  fi
  
  filename="$1"
  
  # Use [ -f ... ] to test if the file exists AND is a regular file
  if [ -f "$filename" ]; then
      echo "The file '$filename' exists and is a regular file."
  else
      echo "The file '$filename' does NOT exist."
  fi
  ```
